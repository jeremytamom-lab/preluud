# Preluud

Application de pré-production : notes d'intention, moodboards, storyboards, découpage technique et planning.

Ce dépôt sert uniquement à distribuer l'app et ses mises à jour : le code source n'y est pas.

- **Télécharger** : voir la page [Releases](https://github.com/jeremytamom-lab/preluud/releases/latest).
- `updates/` : mises à jour de l'interface, signées, installées automatiquement par l'app.

Accès réservé aux comptes invités pendant l'alpha.
